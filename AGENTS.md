## Project
This repository is **Tiger Workflow App**.

## Mandatory workflow for Codex
1. Read this `AGENTS.md` before starting each task.
2. Do not rewrite the whole site.
3. Do not modify unrelated files.
4. Do not connect to a real CRM API unless explicitly requested.
5. After any code change, run `npm run build`.
6. If typecheck exists, run `npm run typecheck`.
7. Report: changed files list, build result, typecheck result, and risks.
8. Any content involving **price, customs clearance, delivery timeliness, customer privacy, or customer cases** must require human review.
9. Codex must not automatically promise business outcomes.
