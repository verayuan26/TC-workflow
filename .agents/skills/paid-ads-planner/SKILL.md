# paid-ads-planner

## 什么时候触发
- 需要制定阶段性投放计划与测试路线图时。
- 需要从同一卖点拆出多广告角度与素材版本时。
- 需要建立投放假设与验证指标时。

## 什么时候不要触发
- 不用于直接拍板预算与最终渠道配比。
- 不用于替代 `tiger-longxia-orchestrator` 做跨团队任务统筹。
- 不用于承诺结果型输出（如“必定降本30%”）。

## 输入材料
- 投放目标（曝光/线索/SQL/成交）。
- 渠道范围（Google/Yandex/YouTube/VK）。
- 可用素材与落地页。
- 历史表现数据与限制条件。

## 工作步骤
1. 明确单渠道目标与转化事件。
2. 拆分2-4个广告角度（痛点/避坑/成本透明/对比）。
3. 每个角度输出素材变体建议（文案、视频、图片）。
4. 定义测试假设、观察窗口、成功判定阈值。
5. 标注追踪要求（UTM、CRM标签、content_id）。
6. 标注必须Vera审核的预算与承诺相关项。

## 禁止事项
- 禁止越权决定预算增减。
- 禁止夸大广告效果与收益预测。
- 禁止无追踪参数就给出投放结论。

## 与 Tiger 自定义 Skills 的关系
- 本 Skill 是投放规划辅助器。
- 任务分发与最终决策遵循 `tiger-longxia-orchestrator` 与 Vera 审核。
