# tiger-longxia-orchestrator

## 1) 什么时候触发
- 当 Vera 提出周目标（月目标拆周）时。
- 当需要把“流量增长目标”拆成可执行任务包时。
- 当需要协调社媒内容、广告投放、CRM反馈、复盘指标时。
- 当任务跨角色（小 S / 小 M / 小 C / 小 A）并需要明确依赖关系时。

## 2) 什么时候不要触发
- 不用于网站基础架构讨论（建站、服务器、底层框架重构等）。
- 不用于替代 Vera 做“最终业务判断”（预算拍板、是否接单、价格策略最终决策）。
- 不用于直接生成最终对外文案（应调用对应内容类 Skill）。

## 3) 需要哪些输入
最少输入：
1. 本周目标（例如：YouTube 留资提升 20%，VK 私信成本下降 15%）。
2. 当前渠道清单（Google / Yandex / YouTube / VK / SEO / CRM）。
3. 当前约束（预算、人力、时间、合规边界）。
4. 现有追踪现状（UTM、埋点、CRM 标签是否已统一）。

建议输入：
- 上周复盘数据（曝光、点击、私信、线索、SQL、成交、成本）。
- 当前主推产品与目标客群。

## 4) 工作步骤
1. **目标澄清**：把 Vera 目标改写成可度量目标（含时间、指标、口径）。
2. **漏斗定位**：标注每个目标位于曝光/点击/留资/成交哪一层。
3. **任务拆解**：按小 S / 小 M / 小 C / 小 A 拆任务，给出负责人、截止时间、输入输出。
4. **五项强检**：逐项检查并补齐：
   - 页面（落地页是否匹配目标客群）
   - CTA（是否清晰且可执行）
   - UTM（source/medium/campaign/content 至少四段）
   - CRM 标签（线索来源、行业、货类、意向级别）
   - 复盘指标（前置+结果指标）
5. **Vera 风险标记**：涉及客户案例/照片/聊天、时效、清关、报价、预算、隐私必须标记审核原因。
6. **JSON标准输出**：严格按《Workflow App AI 任务导入 JSON 标准 V1》输出，字段名固定。
7. **依赖排序**：明确先后顺序和阻塞项（谁等谁）。
8. **提交 Vera 审核项**：仅提交需要业务判断的决策点，不替 Vera 拍板。

## 5) 固定输出格式
必须使用以下模板：

### A. 周目标卡
- 目标名称：
- 时间范围：
- 核心指标（口径）：
- 目标值：

### B. 任务分发表（小 S / 小 M / 小 C / 小 A）
| 任务ID | 角色 | 任务描述 | 输入 | 输出 | 截止时间 | 依赖 |
|---|---|---|---|---|---|---|

### C. 五项强检清单
- 页面：通过/缺失 + 修正动作
- CTA：通过/缺失 + 修正动作
- UTM：通过/缺失 + 修正动作
- CRM 标签：通过/缺失 + 修正动作
- 复盘指标：通过/缺失 + 修正动作

### D. Vera 审核点
- [必须审核] 决策点1：
- [必须审核] 决策点2：

### E. Workflow App JSON（字段固定）
- timezone 固定为：`Asia/Shanghai`
- 所有 task 默认：`status: "AI_DRAFT"`
- 所有 task 必须有：`review_reason`
  - `needs_vera_review=true` 时：`review_reason` 至少 1 条
  - `needs_vera_review=false` 时：`review_reason: []`
- 字段名严禁改动，必须与《Workflow App AI 任务导入 JSON 标准 V1》一致。

## 6) 禁止事项
- 禁止回到“网站基础建设阶段”展开讨论。
- 禁止直接下最终商业结论（如“必须加预算50%”）。
- 禁止省略 UTM 和 CRM 标签检查。
- 禁止输出无负责人、无截止时间的任务。
- 禁止修改 Workflow App 导入字段名。

## 7) 哪些内容必须 Vera 审核
- 预算增减与渠道配比调整。
- 客群优先级变更。
- 销售策略、报价策略、承诺边界。
- 重大内容方向取舍（例如主推市场切换）。
- 客户案例、客户照片、客户聊天记录、客户隐私相关内容。
- 运输时效与清关承诺相关内容。

## 8) 例子
### 好例子
“本周目标：VK 私信成本从 $18 降到 $14（2026-05-27 至 2026-06-02）。小 C 在 48 小时内完成 UTM 与页面CTA联调，小 A 产出广告假设而不拍板预算；任务 JSON 中统一 status=AI_DRAFT，含报价语句任务 `needs_vera_review=true` 且 `review_reason=[\"报价策略\"]`。”

### 坏例子
“这周大家多发点内容，广告也加一点预算，看看效果再说。”
（问题：无指标口径、无角色分工、无追踪方案、无复盘标准、无审核标记）
