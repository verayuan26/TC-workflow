# copywriting-editor

## 什么时候触发
- 文案需要“去空泛、提清晰、增行动性”时。
- 需要同一文案的多标题、多CTA版本测试时。
- 内容已定方向但表达不够口语化时。

## 什么时候不要触发
- 不用于替代业务策略制定。
- 不用于编造事实补齐论证。
- 不用于替代 `tiger-vera-style-script` 的人设表达最终校准。

## 输入材料
- 原文案。
- 目标受众与渠道。
- 目标动作（点击/私信/留资）。
- 禁用词和必须保留信息。

## 工作步骤
1. 标注原文中的空话、套话、弱CTA。
2. 重写标题（3-5个版本）并区分语气。
3. 重写正文，保留事实、删除虚词。
4. 生成2-3个CTA版本并说明适用场景。
5. 标注高风险句交给Vera审核。

## 固定输出格式
### A. 原文问题诊断
- 问题1：
- 问题2：

### B. 标题优化（3-5个）
1. 
2. 

### C. 正文优化版

### D. CTA 版本
- CTA-A（适用场景）：
- CTA-B（适用场景）：

### E. 审核标记
- 需 Vera 审核句：

## 禁止事项
- 禁止加入原文没有的关键事实承诺。
- 禁止使用“行业第一、绝对领先、100%保证”等绝对化用语。
- 禁止把编辑动作变成业务决策动作。

## 与 Tiger 自定义 Skills 的关系
- 本 Skill 是写作层工具，优先级低于 Tiger 核心 Skills。
- 涉及Vera个人判断表达时，必须回交 `tiger-vera-style-script` 或 Vera 本人审阅。
